# Keterangan Akun Belum Teraktivasi

Akun dapat diaktivasi melalui menu Pengguna Aplikasi Mobile di ASIK Dashboard. Untuk mendapatkan akses username dan password, hubungi teman-teman dari program Imunisasi atau PTM. Setelah akun diaktifkan, silakan login kembali menggunakan aplikasi mobile.
