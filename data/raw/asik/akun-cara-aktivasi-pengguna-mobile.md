# Cara Aktivasi Pengguna Mobile

Untuk mengaktifkan akun di ASIK:

1. Pilih menu "Pengguna Aplikasi Mobile" di ASIK Dashboard.
2. Cari NIK atau nama petugas.
3. Ubah status petugas menjadi aktif dengan menggeser tombol menjadi warna hijau.
4. Petugas Puskesmas atau koordinator program bertanggung jawab untuk memastikan validasi dari setiap petugas yang melakukan registrasi di ASIK Mobile.&#x20;
