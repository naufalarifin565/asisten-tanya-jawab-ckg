# Lupa Password Dashboard

Jika lupa password Dashboard ASIK, silakan menghubungi Administrator Puskesmas, Dinas Kesehatan Kabupaten/Kota, atau Dinas Kesehatan Provinsi sesuai kewenangan.

Administrator akan mengirimkan tautan (link) untuk mengatur ulang kata sandi ke email yang terdaftar pada akun Anda.

{% hint style="info" %}
**Catatan:** Tautan atur ulang kata sandi hanya dikirimkan ke alamat email yang terdaftar pada akun pengguna. Pastikan email tersebut masih dapat diakses.
{% endhint %}

<details>

<summary>Panduan Administrator: Mengatur Ulang Kata Sandi Pengguna</summary>

Administrator dapat mengirimkan tautan untuk mengatur ulang kata sandi pengguna melalui Dashboard Sehat IndonesiaKu.

#### Langkah-langkah

1. Masuk ke Dashboard Sehat IndonesiaKu.
2. Buka menu **Kelola Pengguna** → **Akun Pengguna**.
3. Cari dan pilih akun pengguna yang akan diatur ulang kata sandinya.
4. Klik **Kirimkan Link untuk Atur Ulang Sandi**.
5. Pengguna akan menerima email berisi tautan untuk mengatur ulang kata sandi.

</details>
