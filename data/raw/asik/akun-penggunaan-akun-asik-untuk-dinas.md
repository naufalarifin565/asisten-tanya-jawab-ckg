# Penggunaan Akun ASIK untuk Dinas

Saat ini, setiap dinas kesehatan hanya memiliki satu akun untuk mengelola dashboard di ASIK, yang mencakup program Imunisasi, PTM (Penyakit Tidak Menular), bayi balita, remaja, dan ibu hamil.

Dinas kesehatan hanya memegang akses ke dashboard dan tidak terlibat dalam pengelolaan data langsung untuk program-program tersebut.

Akun ini memberikan akses untuk pemantauan dan pengelolaan data secara terpusat melalui dashboard.

<details>

<summary>Apakah Dinas Perlu Mengunduh ASIK Mobile di Handphone?</summary>

Tidak, dinas kesehatan tidak perlu mengunduh ASIK Mobile di handphone. Dinas hanya memegang akses ke dashboard ASIK melalui komputer atau perangkat lain untuk pemantauan dan pengelolaan data.

</details>
