# Ubah Profile di Mobile

Untuk memperbarui informasi profil, ikuti langkah-langkah berikut:

1. Klik menu Pengaturan.
2. Pilih Profil.
3. Data yang bisa diubah meliputi STR, NIK, Nama, dan Profesi.
4. Selesai.
