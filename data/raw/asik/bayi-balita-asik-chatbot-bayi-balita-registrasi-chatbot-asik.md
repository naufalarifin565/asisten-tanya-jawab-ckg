# Registrasi Chatbot ASIK

**Untuk melakukan pencatatan di ASIK Chatbot, ikuti langkah-langkah berikut:**

1. **Buka Aplikasi ASIK Mobile:** Masuk ke aplikasi ASIK di perangkat mobile Anda.
2. **Pilih Profesi sebagai Kader:** Pilih opsi untuk mendaftar sebagai kader dalam aplikasi.
3. **Hubungi Tenaga Kesehatan (Nakes):** Komunikasikan dengan tenaga kesehatan (nakes) untuk mendapatkan persetujuan pendaftaran melalui dashboard ASIK.
4. **Pastikan Pendaftaran Disetujui:** Verifikasi bahwa pendaftaran Anda disetujui agar dapat melakukan input data pengukuran sesuai dengan ketentuan yang berlaku.
