# Cara Melakukan Deteksi Gizi Buruk

Deteksi dini gizi buruk dapat dilakukan dengan mengukur berat badan dan tinggi badan anak secara rutin serta memantau asupan gizi mereka. Gunakan fitur di aplikasi ASIK untuk mencatat dan memantau indikator gizi anak.

Cara menggunakan aplikasi ASIK untuk mendeteksi gizi pada anak:

1. Login ke Aplikasi ASIK: Masuk ke akun kamu di aplikasi ASIK.
2. Pilih Menu Bayi Balita: Pilih menu 'Bayi Balita' dari ASIK mobile.
3. Catat Data: Input data pengukuran berat badan, tinggi badan, dan asupan gizi anak.
4. Pantau Indikator Gizi: Gunakan fitur pemantauan untuk melacak perkembangan gizi anak.
