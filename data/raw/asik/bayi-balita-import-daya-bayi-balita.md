# Import Daya Bayi Balita

Fitur impor data dalam jumlah banyak saat ini sudah tersedia dan dapat digunakan untuk modul bayi dan balita.

Tata Cara Penggunaan:

1. Akses Dashboard: Masuk ke dashboard ASIK
2. Pilih Fitur Unggah Data: Cari dan pilih opsi "Unggah Data" di menu dashboard.
3. Unggah File: Unggah file data yang akan diimpor, sesuai dengan format yang ditentukan.
4. Verifikasi Data: Periksa dan pastikan data yang diunggah sesuai dengan standar yang ditetapkan
