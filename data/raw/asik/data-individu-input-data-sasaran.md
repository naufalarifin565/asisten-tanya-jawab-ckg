# Input Data Sasaran

Tidak semua sasaran harus diinput ulang. Hanya data sasaran yang sudah pernah diinput di e-PPGBM yang akan otomatis muncul di ASIK. Untuk sasaran yang belum ada di ASIK, perlu dilakukan penginputan manual di ASIK agar datanya tercatat dengan lengkap.
