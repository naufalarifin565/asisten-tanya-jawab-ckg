# Pencatatan Data Individu

Pencatatan data individu perlu dilakukan sebelum pelayanan agar semua individu terdata dan pencatatan ke depannya menjadi lebih mudah. Untuk melakukan pencatatan data individu, ikuti langkah-langkah berikut:

1. Pilih menu 'Daftar Individu'.
2. Sebelum menambah data, lakukan pencarian menggunakan Nama atau NIK.
3. Jika data anak tidak ditemukan, tekan tombol 'Tambah Individu'.
4. Isi formulir data individu dengan lengkap.
5. Klik 'Simpan'.

Untuk informasi lebih detail mengenai pencatatan data individu, silakan buka buku panduan melalui tautan ini
