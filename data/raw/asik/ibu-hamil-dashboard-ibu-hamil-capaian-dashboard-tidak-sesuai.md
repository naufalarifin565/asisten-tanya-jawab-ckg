# Capaian Dashboard Tidak Sesuai

Apabila capaian di dashboard ibu hamil tidak sesuai, harap lakukan pengecekan terlebih dahulu. Dashboard memproses penarikan data pada pukul 05.40 dan 17.40 WIB, dan yang ditampilkan adalah capaian H-1.

{% hint style="info" %}
Jika capaian di dashboard ASIK Ibu Hamil masih tidak sesuai, mohon melaporkan aduan melalui [form aduan](https://docs.google.com/forms/d/e/1FAIpQLSdG5r2QKOylsAx7uA6vOzHwoPxy4l0MkiLRHG7OJE-d-x1I6Q/viewform).
{% endhint %}
