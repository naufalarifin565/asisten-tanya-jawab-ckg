# Data Individu Ibu Hamil Tidak Ditemukan

Apabila data individu ibu hamil tidak ditemukan, silakan lakukan langkah berikut:

* Cari data berdasarkan nama atau NIK ibu hamil.
* Disarankan menunggu hingga satu jam setelah data sasaran diinput, atau maksimal 1x24 jam, agar data muncul dalam hasil pencarian.

{% hint style="warning" %}
Jika data masih tidak ditemukan, silahkan melaporkan aduan melalui [form aduan](https://docs.google.com/forms/d/e/1FAIpQLSdG5r2QKOylsAx7uA6vOzHwoPxy4l0MkiLRHG7OJE-d-x1I6Q/viewform) , dengan melampirkan:

* Sebutkan data sasaran yang tidak ditemukan (NIK atau Nama & Tanggal Lahir).
* Lampirkan bukti berupa NIK sasaran yang tidak ditemukan.
  {% endhint %}
