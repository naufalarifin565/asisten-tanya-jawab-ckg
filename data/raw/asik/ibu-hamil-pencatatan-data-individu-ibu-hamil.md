# Pencatatan Data Individu Ibu Hamil

Pencatatan data individu ibu hamil dilakukan khusus untuk ibu hamil yang berlokasi di luar gedung, seperti di Posyandu.

{% hint style="info" %}
Pencatatan ini dilakukan saat ibu hamil pertama kali berkunjung ke Posyandu dan hanya dilakukan sekali pada kunjungan pertama tersebut.&#x20;
{% endhint %}

Setelah pencatatan awal, data ibu hamil akan dipantau secara berkala melalui skrining ibu hamil selama masa kehamilannya dalam kunjungan-kunjungan berikutnya. Selanjutnya, setiap data yang relevan akan diperbarui dan dicatat sesuai dengan perkembangan kondisi ibu hamil dan kebutuhan pemantauan kesehatan.

<details>

<summary>Apakah penginputan sasaran ibu hamil di ASIK dilakukan berdasarkan data riil di wilayah kerja tertentu atau untuk keseluruhan kabupaten?</summary>

Penginputan data sasaran ibu hamil di ASIK dilakukan berdasarkan data riil sesuai dengan wilayah kerja masing-masing. Artinya, kader posyandu atau nakes akan menginput data ibu hamil yang domisilinya berada di wilayah posyandu tersebut, bukan untuk keseluruhan kabupaten.

</details>
