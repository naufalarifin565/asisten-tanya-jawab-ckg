# Cara Mengunduh Tabel Pada level Dinkes Prov/KabKo

1. Pilih salah satu menu: **Kinerja Puskesmas** atau **Cakupan Wilayah**.
2. Pilih salah satu tab: **Imunisasi Rutin Bayi**, **Imunisasi Rutin Baduta**, **Imunisasi Rutin BIAS**, **Imunisasi Rutin WUS**, **Imunisasi Rutin Monev**, atau **PWS Kinerja**.
3. Gulir layar ke bagian bawah.
4. Klik **"Menuju Halaman Download"**.
5. Klik **"Download Excel/CSV"**.
6. Pilih format file yang diinginkan: **CSV** atau **Excel**.
7. Klik **"Download"** untuk mengunduh file ke perangkat Anda
