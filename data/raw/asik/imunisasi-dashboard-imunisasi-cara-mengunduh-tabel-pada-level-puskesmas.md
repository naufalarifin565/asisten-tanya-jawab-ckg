# Cara Mengunduh Tabel Pada Level Puskesmas

* Pilih salah satu menu: **Imunisasi Bayi**, **Baduta**, **BIAS**, atau **WUS**.
* Klik **"Unduh Tabel"**.
* Pilih jenis data: **Individu** atau **Agregat**.
* Pilih spesifikasi data: **Kohort** atau **Capaian**.
  * Untuk **Kohort**, masukkan tanggal lahir anak.
  * Untuk **Capaian**, masukkan tanggal imunisasi, filter jenis imunisasi, dan pencatatan.
* Pilih format file yang diinginkan: **CSV** atau **Excel**.
* Klik **"Unduh Tabel"** untuk mengunduh file ke perangkat.
