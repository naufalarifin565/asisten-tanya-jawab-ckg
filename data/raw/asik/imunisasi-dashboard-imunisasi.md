# Dashboard Imunisasi

**Dashboard Imunisasi** adalah alat yang memudahkan pemantauan dan pengelolaan program imunisasi. Fitur utamanya meliputi:

1. **Menu Kinerja Puskesmas**: Memantau kinerja Puskesmas dalam memberikan layanan imunisasi, mencakup sasaran imunisasi di wilayah Puskesmas serta pengunjung dari luar wilayah.
2. **Menu Cakupan Wilayah**: Menyediakan informasi tentang cakupan imunisasi berdasarkan wilayah, membantu memantau data imunisasi sesuai dengan domisili sasaran.
3. **Data Kinerja**: Menyediakan analisis mengenai pencapaian target imunisasi dan evaluasi kinerja program.
4. **Laporan dan Analisis**: Menawarkan laporan terperinci untuk mengevaluasi efektivitas program imunisasi.

Dashboard ini dirancang untuk memudahkan pemantauan, pengelolaan, dan evaluasi program imunisasi dengan lebih efisien.
