# Penginputan Data Berulang dalam 1 Bulan

Penginputan data berulang dalam satu bulan dimungkinkan. Data ini akan dihitung sebagai data kohort atau berkelanjutan, tanpa menghapus data sebelumnya, dan akan ditampilkan pada tab Jumlah Kunjungan.
