# Unduh Data By Name By Address (BNBA) PTM

Saat ini, unduhan data berdasarkan nama dan alamat (BNBA) untuk PTM dapat dilakukan, namun NIK peserta tidak ditampilkan. NIK telah diganti dengan ID Pasien untuk menjaga keamanan data pribadi.

{% hint style="info" %}
Untuk mengunduh data BNBA PTM, akses dapat dilakukan melalui Dashboard ASIK **pada level Puskesmas. Tidak pada level Dinkes.**&#x20;
{% endhint %}
