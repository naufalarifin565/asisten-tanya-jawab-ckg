# Kesalahan Memasukkan Data

Apabila memiliki kendala salah salah memasukkan data. Mohon dipastikan untuk menginput data skirning PTM dengan benar, karena ASIK masih belum memiliki fitur edit data di dalam aplikasi.\
\
Untuk melakukan perubahan data anak, silahkan untuk melaporkan aduan melalui [form aduan](https://docs.google.com/forms/d/e/1FAIpQLSdG5r2QKOylsAx7uA6vOzHwoPxy4l0MkiLRHG7OJE-d-x1I6Q/viewform)   dengan melampirkan:

1. Informasikan Data Skrining Pasien (NIK atau Nama & Tanggal Lahir)
2. Lampirkan Foto/Screenshot/Video/Screenrecord Kendala
