# Peserta Skrining PTM Tanpa NIK atau KTP

Cara yang perlu dilakukan apabila peserta skrining tidak mempunyai NIK atau tidak membawa KTP:

1. Peserta dapat menggunakan ID pasien sementara saat memasukkan data ke ASIK Mobile (misalnya dengan menggunakan kode wilayah dan tanggal lahir).
2. Data yang dimasukkan akan otomatis tercatat dalam database DTO menggunakan ID pasien sistem.
3. Pada kunjungan berikutnya, NIK peserta dapat diperbarui sesuai dengan KTP.
4. Untuk pelaporan di masa mendatang, tersedia opsi pencarian peserta menggunakan NIK atau nama lengkap dan tanggal lahir sesuai KTP untuk input data.
