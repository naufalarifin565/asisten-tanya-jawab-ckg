# Data Anak Tidak Ditemukan

Jika data anak sekolah dan remaja tidak ditemukan, lakukan pencatatan ulang dan pastikan semua informasi yang dimasukkan akurat dan sesuai.

{% hint style="warning" %}
Jika data masih belum ditemukan, silakan melaporkan aduan melalui [form aduan](https://docs.google.com/forms/d/e/1FAIpQLSdG5r2QKOylsAx7uA6vOzHwoPxy4l0MkiLRHG7OJE-d-x1I6Q/viewform). &#x20;
{% endhint %}
