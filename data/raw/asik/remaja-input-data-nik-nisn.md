# Input data NIK/NISN

Penginputan data skrining siswa usia sekolah dan remaja di ASIK memerlukan NIK. Jika NIK tidak tersedia, pilih opsi "NIK tidak diketahui" pada pengisian data detail individu.&#x20;

{% hint style="info" %}
&#x20;Saat ini, NISN belum bisa digunakan di ASIK.
{% endhint %}
