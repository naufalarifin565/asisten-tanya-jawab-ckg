# Perbedaan Ceria vs ASIK

Untuk memahami perbedaan antara aplikasi Ceria dan ASIK terkait pencatatan Rematri dan TTD, berikut adalah perbandingan antara kedua aplikasi tersebut:

| Aspek              | Aplikasi Ceria                                          | ASIK                                                                                                        |
| ------------------ | ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Penggunaan         | Digunakan oleh siswa untuk mencatat data mereka sendiri | Digunakan oleh kader atau tenaga kesehatan untuk pencatatan data kegiatan skrining di posyandu atau sekolah |
| Keterhubungan Data | Tidak terhubung dengan ASIK                             | Data ASIK tidak terhubung dengan aplikasi Ceria                                                             |
