# Cara Log in User Management

Setelah akun berhasil diaktivasi, pengguna dapat mengakses dan menggunakan fitur di website ASIK. Berikut adalah langkah-langkah untuk login:

{% stepper %}
{% step %}
**Aktivasi Akun**

Pengguna harus terlebih dahulu mengaktifkan akun mereka dengan mengklik tautan aktivasi yang dikirimkan ke email yang terdaftar.
{% endstep %}

{% step %}
**Akses Website ASIK**

Setelah akun diaktivasi, pengguna dapat mengakses website ASIK melalui tautan berikut: <https://sehatindonesiaku.kemkes.go.id/>.
{% endstep %}

{% step %}
**Login ke Website ASIK**

Masukkan username dan password yang telah didaftarkan untuk login ke sistem.
{% endstep %}
{% endstepper %}
