# Cara Melakukan Aktivasi User Management

Cara melakukan aktivasi di dalam user management adalah sebagai berikut:

{% stepper %}
{% step %}
**Pendaftaran Akun oleh Admin/Superadmin**

Admin atau Superadmin mendaftarkan akun pengguna. Setelah proses pendaftaran selesai, akun pengguna akan disimpan di sistem.
{% endstep %}

{% step %}
**Pengguna Menerima Email Aktivasi**

Pengguna akan menerima email aktivasi yang dikirim ke alamat email yang didaftarkan dalam form pendaftaran Administrator.
{% endstep %}

{% step %}
**Klik Tautan Aktivasi**

Pengguna mengklik tautan aktivasi yang diterima melalui email untuk memulai proses aktivasi akun.
{% endstep %}
{% endstepper %}
