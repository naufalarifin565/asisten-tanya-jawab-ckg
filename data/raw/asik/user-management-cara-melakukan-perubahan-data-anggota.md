# Cara Melakukan Perubahan Data Anggota

{% stepper %}
{% step %}
**Ajukan Permintaan Perubahan**

Pengguna meminta perubahan data kepada **Administrator** di tempatnya terdaftar, seperti Puskesmas atau Dinas Kesehatan
{% endstep %}

{% step %}
**Administrator Membuka Menu Akun Pengguna**

Administrator masuk ke **menu Akun Pengguna** di sistem Sehat Indonesiaku (ASIK).
{% endstep %}

{% step %}
**Cari Akun dan Lakukan Perubahan**

Administrator mencari akun pengguna, memilihnya, dan melakukan perubahan yang dibutuhkan.
{% endstep %}

{% step %}
**Simpan Perubahan**

Administrator menyimpan data untuk memastikan perubahan diterapkan.
{% endstep %}
{% endstepper %}
