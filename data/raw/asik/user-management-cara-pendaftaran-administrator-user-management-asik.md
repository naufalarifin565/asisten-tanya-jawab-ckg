# Cara Pendaftaran Administrator User Management ASIK

Berikut adalah langkah-langkah untuk menjadi Administrator di Website ASIK:

{% stepper %}
{% step %}
**Mengisi Formulir Pendaftaran**

Calon Administrator dapat mengisi formulir pendaftaran melalui tautan berikut: <https://link.kemkes.go.id/multi/Links/lists/AdminASIKK>
{% endstep %}

{% step %}
**Pengajuan Akun untuk Pengelola Program**

Pengelola Program yang memerlukan akses dapat meminta akun kepada Administrator di instansi masing-masing, seperti di Puskesmas atau Dinas Kesehatan.
{% endstep %}

{% step %}
**Pengajuan Akun untuk Tamu dan Eksekutif**

Untuk pengguna dengan status Tamu dan Eksekutif, permintaan akun harus diajukan melalui Helpdesk Kemenkes.
{% endstep %}
{% endstepper %}
