# Peran Pengguna di User Management

**Peran pengguna di dalam User Management terdiri dari 3:**

## 1. Kordinator Program

Bertanggung jawab untuk mengelola program kesehatan di wilayah kerja mereka, seperti pengumpulan data, pelaporan, dan pemantauan kegiatan kesehatan di tingkat fasilitas.

## 2. Tamu

Pengguna dengan akses terbatas, biasanya untuk pengawasan atau kepentingan sementara tanpa tanggung jawab pengelolaan data.

## 3. Eksekutif

Pengguna dengan akses tinggi untuk melihat data dan laporan di tingkat strategis, seperti laporan kinerja program, statistik kesehatan, dan analisis data di beberapa wilayah atau level tertentu.

<details>

<summary>Apakah saya bisa berganti peran pada User Management?</summary>

Bisa. Administrator dapat mengubah peran pengguna menjadi: Koordinator Program, Tamu, atau Eksekutif.

Superadministrator (DTO) dapat mengubah peran pengguna menjadi: Administrator, Koordinator Program, Tamu, atau Eksekutif.

</details>
