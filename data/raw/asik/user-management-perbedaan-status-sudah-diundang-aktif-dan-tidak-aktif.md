# Perbedaan Status Sudah diundang, Aktif dan Tidak Aktif

| Status         | Deskripsi                                                                                    |
| -------------- | -------------------------------------------------------------------------------------------- |
| Sudah diundang | Email aktivasi sudah dikirim ke pengguna.                                                    |
| Aktif          | Pengguna telah melakukan aktivasi password dan dapat login ke sistem.                        |
| Tidak Aktif    | Administrator atau Superadministrator telah menonaktifkan akun pengguna melalui penghapusan. |
