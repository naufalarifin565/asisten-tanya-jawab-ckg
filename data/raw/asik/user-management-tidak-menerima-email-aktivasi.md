# Tidak Menerima Email Aktivasi

Jika tidak menerima email aktivasi, Anda dapat meminta Administrator untuk resend (pengiriman ulang) email aktivasi Login. Caranya:

{% stepper %}
{% step %}
Login sebagai Administrator
{% endstep %}

{% step %}
Masuk ke Menu Akun Pengguna
{% endstep %}

{% step %}
Cari pengguna yang ingin dikirim ulang aktivas
{% endstep %}

{% step %}
Klik pengguna tersebut untuk masuk ke halaman detail
{% endstep %}

{% step %}
Klik "Kirim Aktivasi" pada bagian pengaturan ulang kata sandi.
{% endstep %}
{% endstepper %}
